# 2026Q1 13F 季度学习：第一轮

日期：2026-05-19  
范围：P0 管理人优先，P1 平台只做结构信号抽样。  
目标：提炼美股 Radar 的 alpha 输入维度，不抄作业、不自动交易。

## 一页结论

2026Q1 的第一轮 13F 学习给美股 Radar 三个增益：

1. **主线仍在 AI / 数据中心 / 半导体 / 新云 / 电力 / 存储，但交易已经高度拥挤。** Situational Awareness 的 AI 基建多头 + 大额半导体 put，Tudor / Millennium / Citadel 的指数和科技 ETF 期权结构，都提示我们必须把 `crowding_hedge_skill` 做实。
2. **Duquesne 的信号不是单纯 AI，而是“宏观广谱 + 少数集中标的”。** NTRA、INSM、TSM、EWZ / Brazil、YPF、Alcoa 等说明顶级宏观资金在做主题分散和 regime 表达。美股 Radar 不应只盯 AI，也要保留“非 AI 高质量 alpha / 宏观再定价”候选层。
3. **平台型基金的 13F 更适合做拥挤度和宽度指标，不适合做个股买入清单。** Point72 / Millennium / Citadel 的规模、期权和 ETF 暴露显示主题热度，但方向含义要打折。

| INSM | 约 1.89 亿美元 | 生物医药 alpha 样本；不直接进主仓，但可用于学习非 AI 右尾结构 |
| TSM | 约 1.67 亿美元 | AI 制造锚，继续支持我们把 TSM 放入 V6-B / Radar core_reaccel |

Radar 增益：

- `macro_regime_skill` 不能只判断美股科技。要能识别 Brazil、能源、资源、等权指数这种“市场广度 / 再通胀 / 非美 beta”表达。
- `concentration_conviction_skill` 应学习 Duquesne 的风格：真正高信念会非常集中，但不等于我们也能大仓。对我们来说，先做样本学习。
- 美股 Radar 应新增一个低频分层：`non_ai_alpha_watch`。NTRA / INSM 这类不一定属于我们能力圈，但可作为“非 AI alpha 结构”研究样本。

### 3. Tudor Investment Corp

Q1 13F：3515 条，约 538.74 亿美元。  
Top holdings 是 `IWM puts / IWM calls / QQQ puts / QQQ calls`，说明 Tudor 的 13F 对我们最有价值的是宏观期权结构，而不是单票方向。

从 SEC 原始表可见，个股也经常是 long + call + put 同时存在。例如：

- ADBE：long、call、put 同时存在，put 名义大于 long/call。
- AMD：long、call、put 同时存在，put 名义显著。
- GOOGL：long、call、put 同时存在。

Radar 增益：

- `institutional_hedge_signal` 必须区分两类：
  - 主题 / ETF 层：IWM、QQQ、SPY、SMH 的 put/call 结构，用于判断整体 risk regime。
  - 个股层：ADBE、AMD、GOOGL 等 long + put/call，不能简单解读为看多或看空，只能说明该票是可交易风险载体。
- 对 ADBE 的启发：Tudor 不是给我们“买入”或“卖出”信号，只说明 ADBE 是机构愿意交易的高流动性软件风险载体。我们的 ADBE 仍按 Q2 / CEO gate 走。
- 对 AMD / GOOGL / NVDA / QQQ：如果机构期权结构偏重，Radar 应提高拥挤度和事件风险提示。

## 对美股 Radar 的规则升级

### 新增字段

| 字段 | 含义 | 第一轮样本 |
|---|---|---|
| `macro_regime_fit` | 当前宏观环境是否支持这类交易 | Duquesne 的 EWZ / RSP / YPF / commodities |
| `institutional_validation` | 是否被高质量机构作为主题样本验证 | SA 的 AI infra、Point72 的 NVDA/ANET |
| `institutional_hedge_signal` | 是否有显著 put/call / ETF 对冲结构 | SA、Tudor、Millennium、Citadel |
| `crowding_penalty` | 主线强但交易拥挤时的惩罚 | NVDA / AMD / AVGO / TSM / QQQ / SMH |
| `non_ai_alpha_watch` | 非 AI 高质量 alpha 样本层 | Duquesne 的 NTRA / INSM |
| `position_role` | 输出角色，不直接输出买卖 | research / watch / pullback / V6B_candidate / manual_attack_candidate |
