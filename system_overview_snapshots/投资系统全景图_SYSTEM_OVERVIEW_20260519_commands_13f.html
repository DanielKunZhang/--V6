2026-04-27 股票仓位状态带：
7+1 定义的是长期结构，不等于任何时点都必须打到 95% 股票仓位。
当前股票仓位以后统一分三档理解：进攻态 90-95%、常态 80-90%、保守态 70-80%。
当目标席位还没到舒服价格，或验证不足以支持加仓时，回流出来的现金统一视为 过渡期等待资本，不是系统偏离；不允许为了把仓位硬打到 95% 而高价硬买目标席位。状态带看的是有效股票仓位质量，不是只看股票比例本身；若 90%+ 主要由历史超配或旧仓残留撑出来，也不算进攻态。
2026-04-29 三层资金结构正式版：
7+1 回答“长期由谁构成组合”，95 / 90 / 80 回答“任何时点股票仓位打到多少算合理”，三层资金结构回答“每一块资本到底负责什么收益任务”。
以后统一按总资产口径理解为：底盘层 40-60%、高概率进攻层 20-35%、Optionality层 5-15%；未落位资金统一归入 过渡期等待资本，由状态带决定，不强行打满。
底盘层负责活下来和长期复利，进攻层负责把年化拉高，Optionality层负责提供上限。进攻层可以阶段性贡献部分已实现收益，但不允许被生活费需求反向绑架卖点，更不允许为了提款破坏底盘纪律。

2026-04-23 新增：FCF真实性核查（巴菲特式防呆）
每份正式 /估值 报告，在进入 DCF 前必须固定回答四问：
1) SBC 有没有被变相加回，或被 non-GAAP 口径美化？
2) CapEx 是否低估了维护性资本开支，只看见账面轻资产而忽略真实再投资？
3) 营销 / 补贴 / 渠道返利 中，是否存在“伪轻资产”投入，被会计处理掩盖？
4) 当前 FCF 是否处在周期高点，不能当作常态 Owner Earnings？
执行纪律：所有 Adjusted EBITDA / Adjusted EPS / 其他 adjusted 指标只能辅助披露，不能主导内在价值判断；主锚固定为 GAAP EBIT → FCFF / Owner Earnings → DCF / EV/FCF。

1) 最新外部真实数据搜索结果；

3) 验证状态：增强 / 持平 / 转弱；
4) 财报与外部现实是否互相印证；
5) 核心来源与日期清单。
若缺乏足够外部数据，只能给保守仓位结论，不得直接因财报好看而升级仓位。
最终判断采用“综合毛估估”：把财报、外部现实、行业位置、管理层、赔率与风险合在一起做区间判断，而不是迷信单一模型或单一数据。

接班操作顺序（量化主系统）
  1. 先确认账户可投资现金：只看现金 / 货币基金 / 近现金，不看总资产。
  2. 确认当前应该跑哪条线：$20k~$25k 小资金线；$150k+ 才进入大资金线 shadow / pilot / primary 阶段。
  3. 先做 selector / gate / realism / stress / dry-run：任何一步不过，都不准把系统描述成“ready for live”。
  4. 先 simulate / paper，再 live：尤其要看真实点差、snapshot 新鲜度、账户限制、最小下单单位。
  5. 日报要对比理论与现实：理论目标仓位、实际盘口、可成交性、模拟成交结果必须能对应得上。
