# 中国税务居民境外投资个税计算规格 v1

## 目标

把富途香港券商 PDF 对账单转换为个人所得税 APP 境外收入申报可参考的数据包，并保留可审计底稿。

## 官方口径映射

本版按以下申报逻辑设计：

- `财产转让所得`：股票/ETF/ADR 已平仓交易的年度净收益，税率 20%
- `利息股息红利所得`：现金股息毛额，税率 20%
- `境外所得抵免`：境外已预扣税按限额抵免，超限部分预留 5 年结转记录

参考文件：

- 《中华人民共和国个人所得税法》
- 《中华人民共和国个人所得税法实施条例》
- 财政部 税务总局公告 2020 年第 3 号《关于境外所得有关个人所得税政策的公告》
- 个人所得税年度自行纳税申报表 B 表及填表说明
- 境外所得个人所得税抵免明细表及填表说明

## 锁死规则

| 规则 | v1 实现 |
| --- | --- |
| 仅统计当年已实现盈亏 | 只处理年度内 `SELL` 并能匹配成本的交易 |
| 未平仓浮盈浮亏不计税 | 不读取期末市值做计税 |
| 年度盈亏互抵 | 全年度已实现收益与亏损合并净额 |
| 年度净亏损税额为 0 | `max(年度净收益, 0) × 20%` |
| 资本亏损不可结转 | 写入规则常量，报告提示 |
| 交易成本扣除 | 买入侧费用进原值，卖出侧费用进合理税费 |
| 股息红利单独计税 | 股息毛额 × 20%，境外预扣税限额抵免 |
| 无关项剔除 | 入金、出金、融资利息、基金申赎现金流不计入 v1 |

## 成本匹配

默认采用 FIFO：

1. 若启用 `--auto-derive-opening-lots`，先用目标年度之前的月结单推导期初剩余持仓 lot。
2. 再叠加 `config/opening_lots_2025.csv` 的手工 lot；同一 `symbol + region + currency` 下手工录入优先。
3. 目标年度内买入形成新的 lot。
4. 卖出数量超过可用 lot 时，不强行估算成本，写入 `warnings.csv`。

这个设计避免把未知成本误算成 0，也避免把未平仓浮盈浮亏错误纳入计税。

## 自动推导期初 lot

当目录内存在 `2024-*.pdf`、`2023-*.pdf` 等更早月结单时，脚本可以自动：

1. 读取这些历史月结单中的股票/ETF/ADR 买卖记录；
2. 按 FIFO 扣减历史卖出；
3. 把目标年度开始前仍未卖出的剩余 lot 输出为 `derived_opening_lots.csv`；
4. 将其作为目标年度 `opening lots` 参与计税。

该功能可以显著减少手工填写，但前提是历史月结单覆盖到了最初建仓年度。

## 汇率

金额最终折算为 CNY。v1 使用 `config/fx_rates_2025.csv` 中的年度汇率表。

正式申报前应复核：

- 采用税务机关认可的人民币汇率中间价
- 对应纳税年度与申报时点是否匹配
- USD/HKD/CNH 是否需要分别填报

## 个人所得税 APP 输出参考

`tax_app_reference.csv` 按以下字段输出：

- `income_type`：财产转让所得 / 利息股息红利所得
- `country_or_region`：美国 / 中国香港 / 人工覆盖地区
- `gross_income_rmb`：收入额
- `property_original_value_rmb`：财产原值
- `reasonable_tax_fee_rmb`：合理税费
- `taxable_income_rmb`：应纳税所得额
- `tax_rate`：20%
- `tax_before_credit_rmb`：抵免前应纳税额
- `foreign_tax_paid_rmb`：境外已缴税额
- `credit_used_rmb`：本年可抵免额
