# 26 年 V6-A 策略仓配置 — 2026-05-19

## 0. 结论

当前可扩容的 V6 策略仓，准确说是 **V6-A**。V6-B / 美股 Radar 暂时只是研究输入和候选池验证，不占正式策略仓预算。

V6-A 是独立策略仓，不和主观进攻仓混在一起。它的任务是用系统化规则提高资金效率，但前提是执行稳定、可复盘、可暂停。

当前 V6 不直接给大仓位，只按三段走：

| 阶段 | 总资产占比 | 约对应金额 | 富途内占比 | 状态 |
|---|---:|---:|---:|---|
| V6-A Pilot | 约 1%-2% | $5,000 左右 | 约 2%-3% | 当前阶段 |
| V6-A 第一档扩容 | 5%-8% | 约 $20,000-$32,000 | 约 9%-15% | 通过 pilot 后才允许 |
| V6-A 第二档扩容 | 10%-12% | 约 $40,000-$47,000 | 约 18%-22% | 至少 3 个月实盘稳定后再讨论 |

暂不讨论 15%+。V6-A 还没有资格吃掉组合主预算。

如果未来 V6-B 的 Sharpe、回撤、稳定性和真实可执行性显著优于 V6-A，或者能和 V6-A 低相关互补，届时再把预算从“V6-A 策略仓”升级为“V6-A + V6-B 组合策略仓”，并重新讨论整体 V6 是否可以超过 10%-12%。

## 1. V6-A 当前定位

V6-A 不是：

- 不是主观进攻仓。
- 不是现金替代。
- 不是因为回测好就能直接重仓的系统。
- 不是用来弥补 PDD / 腾讯超配调整焦虑的工具。

V6-A 是：

- 独立策略仓。
- 只用富途执行账户出预算。
- 先小额真实验证，再按 gate 扩容。
- 每次扩容都必须能回答：真实执行有没有问题、回撤是否可控、是否能稳定复盘。

V6-B / 美股 Radar 当前是：

- 研究输入。
- 动态候选池。
- 模拟 / 回测 / live-forward 观察对象。
- 不占 V6-A 的 5%-8% 或 10%-12% 扩容预算。

## 2. 阶段 0：当前 V6-A 5k pilot

当前目标：完成真实执行闭环，不追求收益。

| 项目 | 规则 |
|---|---|
| 预算 | $5,000 左右 |
| 总资产占比 | 约 1%-2% |
| 富途内占比 | 约 2%-3% |
| 交易方式 | 手动确认，不自动下单 |
| 目标 | 验证真实订单、滑点、reconciliation、managed state、日报、kill switch |
| 复盘点 | 2026-05-26 V6-A 执行卡 |

5k pilot 的成功标准不是赚多少钱，而是：

- 没有误卖价值主仓。
- managed state 和真实持仓一致。
- 每日计划、执行、复盘链路能跑通。
- 信号出现时能按规则处理，而不是临场情绪化。
- 真实滑点、换手、交易成本没有明显超出预期。

## 3. 从 5k 升到 5%-8%

只有同时满足以下条件，才允许 V6-A 从 5k pilot 升到总资产 5%-8%：

| Gate | 要求 |
|---|---|
| 执行 gate | 至少完成 2 周真实 pilot，订单、持仓、日报、reconciliation 没有重大错误 |
| 风控 gate | pilot 最大回撤没有触发暂停；若有回撤，原因可解释 |
| 交易 gate | 滑点、换手、最小订单规模在富途账户可执行 |
| 心理 gate | 用户能按日报和执行卡行动，不因单日波动干预系统 |
| 资金 gate | 资金来源来自富途现金或腾讯/PDD/IT 回流，不动 RSU 和国内账户 |
| 策略 gate | V6-A baseline 仍有效；V6-B 未通过前不占扩容预算 |

第一档扩容建议：

- 先到总资产 5%，约 $20,000。
- 跑满 2-4 周后，如果执行仍稳定，再到 8%，约 $32,000。
- 不从 $5,000 一步跳到 $32,000。

## 4. 从 5%-8% 升到 10%+

V6-A 的 10%+ 不是短期目标，必须等更长实盘记录。

允许讨论 10%-12% 的条件：

- 至少 3 个月真实运行记录。
- 经历过一次 risk-on / risk-off 或调仓周期。
- 没有 managed state、误卖、重复下单、漏单等严重问题。
- 实盘结果没有明显偏离回测逻辑。
- 最大回撤在预设范围内，且用户能坚持执行。
- V6-B 若要加入整体 V6 预算，必须完成 standalone、V6-A 对比、组合测试和 live-forward。

第二档扩容建议：

- 先从 8% 到 10%。
- 10% 稳定后，再讨论 12%。
- 12% 以上至少等 6 个月记录，不在当前阶段讨论。

## 5. 暂停 / 降权规则

出现以下情况，V6 不扩容，必要时降回 5k 或暂停：

- managed state 与真实持仓不一致。
- 出现可能误卖价值主仓的风险。
- 日报 / 计划 / reconciliation 任一关键链路不稳定。
- pilot 或扩容后回撤超过预设阈值，且原因不可解释。
- 用户开始频繁手动干预系统信号。
- V6 与主观进攻仓高度同向，导致 AI / 半导体 / 高 beta 主题暴露过高。
- V6-B 结果来自 lookahead 或数据污染，不能证明真实增量。

## 6. 资金来源

V6-A 扩容资金只来自：

1. 富途现金。
2. 富途腾讯减仓回流。
3. PDD 减仓回流。
4. IT 等非主线仓回流。

V6-A 扩容资金不来自：

- 腾讯 RSU。
- 国内 A 股账户。
- 港股通底仓。
- 税务不合适的账户腾挪。

原因很简单：V6-A 是美元执行策略，应该放在富途执行账户里，不要把全资产抽象成一个可随意挪动的钱包。

## 7. 与主观进攻仓的关系

V6 和主观进攻仓分开管理：

| 项目 | 主观进攻仓 | V6 |
|---|---|---|
| 依据 | 财报、估值、行业趋势、仓位纪律 | 系统信号、replay、执行质量 |
| 标的 | NVDA、ADBE、泡泡玛特、NU、PDD 等 | 当前 V6-A；未来可能加入 V6-B |
| 执行 | 人工判断 + 分段 | 系统计划 + 人工确认 |
| 复盘 | 财报和 thesis | 信号、滑点、回撤、执行链路 |

不能因为 V6 买了某只股票，就跳过主仓的估值和财报复核；也不能因为主仓看好某只股票，就强行影响 V6 信号。

## 8. 当前正式口径

截至 2026-05-19：

- V6-A 当前阶段：5k pilot。
- 当前总资产目标：约 1%-2%。
- 第一档扩容目标：通过 pilot 后，总资产 5%-8%。
- 第二档扩容目标：至少 3 个月实盘稳定后，讨论 10%-12%。
- 当前不讨论 15%+。
- V6-B / 美股 Radar 仍是研究 / 模拟 / 对比，不占正式扩容预算。

一句话：当前能扩容的是 V6-A；V6-B 先证明 Sharpe、回撤和可执行性，再讨论并入整体 V6。
