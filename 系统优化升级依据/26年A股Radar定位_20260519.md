# 26 年 A股 Radar 定位 — 2026-05-19

## 0. 结论

A股 Radar 当前是训练仓和研究输入，不是大资金进攻仓。

它的目标不是马上赚钱最多，而是用小钱训练：

- 主线识别。
- 龙头 / 中军 / 补涨判断。
- 买点过滤。
- 退潮信号。
- 复盘和样本积累。

正式定位：

| 项目 | 结论 |
|---|---|
| 当前身份 | A股 Radar 训练仓 |
| 当前资金 | 5 万 RMB |
| 第一阶段上限 | 5 万 RMB |
| 通过样本后上限 | 10 万 RMB |
| 更高上限 | 20 万 RMB，至少 100 笔样本后再讨论 |
| 是否大仓 | 否 |
| 是否自动交易 | 否，长江证券手动下单 |

一句话：A股 Radar 是训练交易判断和主线敏感度的工具，不是 26 年组合的主要资金引擎。

## 1. 仓位路径

| 阶段 | 资金规模 | 条件 |
|---|---:|---|
| Phase 1A 训练 | 5 万 RMB | 当前阶段 |
| Phase 1B 小幅扩容 | 10 万 RMB | 至少 50 笔真实样本，正期望，且最大回撤可控 |
| Phase 2 验证仓 | 20 万 RMB | 至少 100 笔真实样本，经历一次退潮期仍能控制回撤 |
| Phase 3 再讨论 | 50 万 RMB | 只在形成稳定方法后讨论；同时评估 PTrade/QMT 等工具 |

当前只执行 Phase 1A：5 万 RMB。

## 2. 升级条件

从 5 万升到 10 万，必须同时满足：

- 至少 50 笔真实交易样本。
- 样本按主线、龙头/中军/补涨、买点、卖点、盈亏原因记录完整。
- 扣除手续费和滑点后仍为正期望。
- 最大回撤不超过训练资金的 10%-12%。
- 亏损不是靠补仓扛回来，而是靠规则退出和下一笔机会修复。
- 退潮信号至少触发过一次，并证明能降低损失。

从 10 万升到 20 万，必须同时满足：

- 至少 100 笔真实样本。
- 经历至少一次市场退潮或主线切换。
- 胜率、盈亏比、平均持仓天数、最大单笔亏损、最大连续亏损都有记录。
- 不依赖单一行情或单一题材。
- 用户能按执行卡行动，而不是盘中情绪化追涨杀跌。

## 3. 单票和组合限制

Phase 1A：5 万 RMB 阶段：

| 项目 | 限制 |
|---|---:|
| 单票初始仓 | 5,000-10,000 RMB |
| 单票上限 | 15,000 RMB |
| 同时持仓数 | 3-5 只 |
| 单日新增 | 原则上不超过 2 只 |
| 单日最大亏损预警 | 1,000 RMB |
| 总回撤暂停线 | -5,000 RMB |

触发总回撤暂停线后：

- 停止新开仓。
- 做 20 笔复盘。
- 重新检查主线判断和买点过滤。
- 不允许用加大仓位追回损失。

## 4. A股 Radar 与其他仓位的关系

A股 Radar 不和这些混在一起：

- 不和底仓混。
- 不和主观进攻仓混。
- 不和 V6-A 混。
- 不和 V6-B / 美股 Radar 混。

它只负责 A 股训练和样本积累。

| 模块 | 关系 |
|---|---|
| 底仓 | 无关，不用底仓资金训练 Radar |
| 主观进攻仓 | 可提供主线观察，但不共享仓位 |
| V6-A | 无关，V6-A 是美股系统策略 |
| V6-B / 美股 Radar | 方法论可互相学习，但样本分开 |
| 长江证券 | 当前手动下单账户 |

## 5. 交易前必须回答

每笔 A股 Radar 交易前必须回答：

1. 当前主线是什么？
2. 买的是龙头、中军、补涨，还是套利？
3. 买点来自突破、回踩、分歧转一致，还是超跌反弹？
4. 如果错了，卖出条件是什么？
5. 这笔交易最多亏多少？
6. 这笔交易对样本库有什么训练价值？

回答不了，就不买。

## 6. 复盘字段

每笔交易至少记录：

- 日期。
- 标的。
- 所属主线。
- 龙头 / 中军 / 补涨 / 其他。
- 买入理由。
- 买入价格。
- 卖出理由。
- 卖出价格。
- 盈亏。
- 是否遵守计划。
- 错误类型。
- 下次改进。

## 7. 当前正式口径

截至 2026-05-19：

- A股 Radar 当前资金：5 万 RMB。
- 不扩大到 10 万，直到至少 50 笔真实样本证明正期望。
- 不考虑自动交易。
- 不接长江证券 PTrade / QMT / miniQMT 委托接口。
- FutuAPI 可用于行情、K 线、成交额、MA5/MA10、执行卡生成。
- 真实交易由用户在长江证券手动下单。

一句话：A股 Radar 先训练，不扩仓；先证明能稳定少亏和小赚，再讨论变成更大资金模块。
