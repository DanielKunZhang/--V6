## 使用原则

1. 原始 HTML / PDF / 脚本继续保留在原位置。
2. 这里优先写 markdown 摘要、规则、结论与索引。
3. 能形成长期判断的，优先进 `00_System`、`01_Portfolio`、`02_Companies`。
4. 输入型学习材料优先进 `04_Research_Notes` 或 `08_Learning_Tracks`。
5. 临时想法先放 `99_Inbox`，成熟后再归档。
6. `latest.html / latest.md / latest.json` 类治理输出以最新产物为准；知识库负责沉淀边界、规则、读法和索引，不复制整份动态报告。
